MVP :-
Phase 1 focuses on building the foundational infrastructure for the automated code review bot without using AI. The primary goal of this phase is to create a reliable system that integrates with GitHub Pull Requests, analyzes changed JavaScript files using ESLint, and posts automated review comments directly on the PR. The workflow begins when a developer opens or updates a Pull Request, which triggers a GitHub Action configured in the repository. The action checks out the PR code, installs dependencies, and executes the review bot script. The bot then uses the GitHub API to retrieve the list of changed files and their corresponding diff patches, ensuring that only modified JavaScript files are analyzed instead of the entire repository. ESLint is executed programmatically on these changed files to detect issues such as unused variables, style violations, or potential code quality problems.
A critical part of this phase is diff mapping, where ESLint-reported file line numbers are converted into GitHub diff positions so comments can be attached accurately to the modified lines inside the Pull Request view. Since GitHub review comments operate on diff positions rather than actual file line numbers, the bot parses patch data and builds a mapping between file lines and diff positions before posting inline review comments through the GitHub Review API. Additionally, the system supports a configurable .reviewbot.yml file that allows teams to enable, disable, or customize checks and ignore specific folders or ESLint rules. By the end of Phase 1, the project delivers a fully functional automated review bot capable of running inside CI/CD pipelines, performing static analysis, and generating inline Pull Request feedback automatically.
